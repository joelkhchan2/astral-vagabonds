# Session structure for Astral Vagabonds

Sessions 1 through 3's prep docs converged on the same shape without anyone planning it that way. This skill names that shape so it's a deliberate template going forward, not something re-derived from scratch each time. Worked examples: `sessions/Session 2 Prep.md`, `sessions/Session 3 Prep.md`.

## The skeleton

1. **Where things stand, going in.** A short recap block at the top of the prep doc: open threads, last session's fallout, current rank/money/ship state. This is for the DM's own orientation, not for the players.
2. **Cold open.** Comedic or warm by default (per the 70/20/10 tone compass), short, and it's what actually kicks the session's job or plot into motion. This is a real scene with a beginning and a landing beat, not a recap.
3. **Main content.** The job, the voyage, the location, whatever the session is actually about. This is usually the longest section and the one with the most branch points.
4. **Social beats, one per PC, spotlighted separately or joined.** Both PCs need a real scene, not just a mention. Look first for a way to fold both into one joint scene (his numbers, her instinct, both reading the same wrongness) before defaulting to two solo beats in the same session, per the standing design principle in `CLAUDE.md`. NPC crew B-plot material lives here too.
5. **Battle, if the job calls for it.** Not mandatory every session. Combat is the second pillar, behind social, per `campaign/Campaign Overview.md`'s pillar priority. When it's in, calibrate it so it's survivable and give it real stakes, not a token scuffle; when it's out, say so explicitly in the prep doc so nobody preps a fight that isn't coming.
6. **Bastion actions / downtime**, when the voyage loop calls for one. Facility decisions, ship stuff, the things that happen at a berth or during a leg with nothing else going on.
7. **Return to port / fallout.** Rumors, Manifest Board movement, consequences of what the crew did (this session or earlier ones catching up to them).
8. **Ending: a hook, a mystery, or a cliffhanger.** Every session prep ends on something that carries forward, named explicitly so it doesn't get lost between sessions. This is also the point to check `sessions/Session Ideas.md` for anything that's ready to seed here, and to add anything new that surfaces but doesn't get used.

## How to use it

- **This is a skeleton, not a checklist to fill mechanically.** A session can skip battle entirely (Session 2 had none, by design) or fold two beats together. The point is knowing what's normally there so a deliberate skip is a choice, not a gap.
- **Start a new prep doc from `sessions/Session Prep Template.md`.** It has these sections pre-titled and ready to fill in.
- **Player agency still applies inside every beat.** Beat 4 in particular: describe the situation and the spotlight opportunity, never script what Orena or Aerion choose, feel, or do. See the hard rule in `CLAUDE.md`.
- **Follow the tone compass through the whole skeleton, not just the cold open.** A hot ending (real danger, a genuine cliffhanger) is fine occasionally, but if the last session already ran hot, counterweight toward warmth in this one, per the DM-style notes in `CLAUDE.md`.
