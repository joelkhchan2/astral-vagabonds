# References

Source material for building out the campaign — official/third-party rulebooks, not campaign canon. Nothing in here overrides `CLAUDE.md` or the docs in `campaign/`, `rules/`, etc.; it's what we pull from and adapt, not what we follow verbatim.

| File | Use |
|---|---|
| [`Astral Adventurer's Guide.md`](Astral%20Adventurer's%20Guide.md) | Core Spelljammer/Astral rules — canon anchor for `rules/Rules & Systems.md` |
| [`Boo's Astral Menagerie.md`](Boo's%20Astral%20Menagerie.md) | Creature stat blocks for Gabrielle's bestiary and wildspace encounters |
| [`SW5E_Player's Handbook Complete Edition 1.2.md`](SW5E_Player's%20Handbook%20Complete%20Edition%201.2.md) | Star Wars 5e — starship combat structure (crew roles, maneuvers) to adapt for ship-to-ship encounters |
| [`Spelljammer Academy.md`](Spelljammer%20Academy.md) | Community Spelljammer reference/expansion material |
| [`Sigil and the Outlands.md`](Sigil%20and%20the%20Outlands.md) | Planar reference — useful if the campaign ever touches the Outlands/planar travel |
| [`Morte's Planar Parade.md`](Morte's%20Planar%20Parade.md) | Planar NPCs/creatures — same use case as Sigil |
| [`Quests from the Infinite Staircase.md`](Quests%20from%20the%20Infinite%20Staircase.md) | Adventure module material — possible encounter/plot seeds |

**Note:** these are large converted files (the SW5E one is ~2.7MB). Grep them for specific sections rather than reading whole files. This repo is private, so keeping full reference text alongside prep is fine for personal use — just don't move it into a public repo as-is, since it's someone else's published material, not ours.
